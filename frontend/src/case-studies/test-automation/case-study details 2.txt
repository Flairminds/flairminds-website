**Key Features of the Solution** 
1. **100% Automated End-to-End Flow**   
The script launches XMPS 2000, creates a new project, adds a user-defined tag, saves or 
cancels it, and verifies the exact number of rows in the grid — **all hands-free**. 
2. **Complete Test Isolation**   
Every test starts with a **fresh instance** of XMPS 2000. No leftover data, no flaky 
behavior — **100% repeatable**. 
3. **Smart & Safe Dialog Handling**   
When the app shows “Save Current Project?” dialog, our script intelligently clicks **“No” 
only if it appears** — otherwise it continues smoothly. 
4. **Two Critical Business Scenarios Fully Validated**   - Add tag → Save → Verify **1 row** appears   - Add tag → Cancel → Verify **0 rows** remain (no accidental data) 
5. **Professional HTML Report with Embedded Screenshots**   
After execution, we generate a beautiful, shareable HTML report that shows:   - Pass/Fail summary   - Execution time   - **Full-screen screenshot automatically captured and embedded on any failure** — so 
debugging is instant. 
**Most Important: We Followed Industry Best Practice — Page Object Model (POM)** 
This is **not just scripting** — we built this using the **same design pattern used by 
Google, Microsoft, Amazon, and all Fortune 500 companies**. 
The **Page Object Model** means: - All UI interactions (clicks, typing, navigation) are cleanly separated into dedicated classes 
(`MainWindow`, `ProjectWindow`, `NewTagDialog`) - Test cases only describe **WHAT** should happen — in simple, readable English-like 
code - If tomorrow the button name changes from “New” to “Create Project”, we fix it in **one 
place only** — all 100+ tests automatically work - Even a new team member or business analyst can **read and understand** the tests 
without knowing coding 
This makes our framework **highly maintainable, scalable, and future-proof**.
